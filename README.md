# Nimble Magni

Prototype convoy action game. Original setting in the Magni dungeon tone. Act structure is *inspired* by classic dark-fantasy campaigns (wilds → desert → temple → highlands → keep) — original names, original 8-bit sprites, no licensed IP.

## Run

```bash
python -m http.server 8765
```

Open `http://127.0.0.1:8765/index.html`

## Controls

- WASD / swipe — snake-lock move
- P / Space — pause
- T — skill tree
- Walls and tail-bite end the run

## Heroes

Warrior, Paladin, Rogue, Mage, Necromancer, Druid — kits stay as in this prototype (Whirlwind, Chain Lightning, Blood Wave, etc.).
